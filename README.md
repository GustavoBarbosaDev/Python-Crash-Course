# Python Crash Course — Estudos

Repositório pessoal de estudos acompanhando o livro **Python Crash Course** (Eric Matthes). Aqui ficam minhas anotações em forma de comentários no código e a resolução dos exercícios de cada capítulo.

> Este não é um projeto de portfólio, é um caderno de estudos. O código é simples de propósito — o foco é fixar os conceitos do livro, não demonstrar arquitetura ou boas práticas avançadas.

## Estrutura

Cada capítulo tem sua própria pasta, dividida em:

- `notas/` — scripts com os exemplos do capítulo, comentados explicando o conceito.
- `exercicios/` — resolução dos exercícios propostos no fim do capítulo, com o enunciado como comentário no topo do arquivo.

```
cap02_variaveis_e_tipos_de_dados/
    notas/
        hello_world.py
        variaveis.py
        tipo_string.py
    exercicios1/
        simple_message.py
        simple_messages.py
```
